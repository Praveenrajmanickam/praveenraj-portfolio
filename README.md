# Praveenraj Manickam · Portfolio

Personal portfolio website: a story-driven, single-page site for recruiters.

Static HTML/CSS/JS, no build step: `index.html`, `style.css`, `main.js`, `assets/`.

## Preview locally
    python3 -m http.server 8080    # then open http://localhost:8080

## Host
- **GitHub Pages:** Settings → Pages → Deploy from branch → `main` / root.
- **Netlify / Vercel:** import this repo; no build command, publish directory `/`.
